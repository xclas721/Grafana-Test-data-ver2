## 路由現況（與 `router/index.ts` 同步）

- 公開 Layout（`PublicLayout`）
  - `/` → `LandingPage`
  - `/front/login` → `FrontLoginPage`
  - `/front` → `FrontPage`（需前台登入）
  - `/login` → `LoginPage`（管理登入）
- 後台 Layout（`MainLayout`，需後台登入）
  - `/dashboard`
  - `/users`, `/members`
  - `/components/*`（`guide/buttons/forms/data/modal/feedback`）
  - `/tools/*`（`guide/files/format/validation`）
  - `/examples/*`（`guide/api/form/store`）
  - `/about`
- 錯誤與保底：`/401`, `/404`, `/500`, `/:pathMatch(.*)* -> /404`

## 技術與樣式重點

- Vue 3 + TypeScript + Vite
- Pinia + Vue Router + Vue I18n
- Tailwind CSS v4 + DaisyUI
- 主題：`brainwave` / `brainwave-dark`（含多主題切換）
- 通知與對話：SweetAlert2（`src/shared/utils/message.ts`）
