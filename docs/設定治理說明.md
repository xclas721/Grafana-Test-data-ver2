# 設定治理說明（前端）

本文件定義前端設定的來源、命名規則與部署規範，降低「本地可跑、部署失敗」的風險。

---

## 1. 設定來源優先序

以 `appConfig` 為單一入口，優先序如下：

1. `window.__APP_CONFIG__`（執行期注入）
2. `import.meta.env.VITE_*`（建置期注入）
3. 程式內預設值

---

## 2. 目前主要設定鍵

- `VITE_API_BASE_URL`：後端 API 位址（最重要）
- `VITE_FRONTEND_CONTEXT_PATH`
- `VITE_FRONTEND_PORT`
- `VITE_BACKEND_API_TIMEOUT`
- `VITE_PAGE_SIZE`
- `VITE_SYSTEM_ID`
- `VITE_BACKEND_CONTEXT_PATH`

---

## 3. 命名與維護規範

- 僅使用 `VITE_*` 讓 Vite 注入。
- 新增設定時，需同步更新：
  - `src/shared/config/appConfig.ts`
  - `.env.example`
  - `README.md` 環境變數段落

---

## 4. 部署規範

- Vercel 至少要設定 `VITE_API_BASE_URL`
- URL 不帶尾斜線，避免重複斜線
- 後端 CORS 要包含前端正式網域

---

## 5. 文件要求

設定文件應包含以下內容：

- 有單一設定入口（本專案為 `appConfig`）
- 清楚列出必填與選填項目
- 由版本控制系統與程式碼一併管理
