# 權杖儲存策略說明

## 用途

將「token 存哪裡」抽象成可替換策略，預設為 `localStorage`；高敏感或需關閉分頁即登出時，可改為 `sessionStorage` 或自訂實作（例如僅記憶在記憶體）。

## 使用方式

- **預設**：不需改寫，後台 token 用 `auth_token`（localStorage）、前台 token 用 `front_auth_token`（localStorage）。
- **改為 sessionStorage**：在 `main.ts` 或 app 初始化處呼叫：

```ts
import {
  setAuthTokenStrategy,
  setFrontTokenStrategy,
  createSessionStorageStrategy
} from '@/shared/tokenStorage'

setAuthTokenStrategy(createSessionStorageStrategy('auth_token'))
setFrontTokenStrategy(createSessionStorageStrategy('front_auth_token'))
```

- **自訂實作**：實作 `TokenStorageStrategy`（`get` / `set` / `remove`），再傳入 `setAuthTokenStrategy` / `setFrontTokenStrategy`。

## 檔案

- `src/shared/tokenStorage/types.ts`：介面定義
- `src/shared/tokenStorage/localStorageStrategy.ts`：localStorage 實作
- `src/shared/tokenStorage/sessionStorageStrategy.ts`：sessionStorage 實作
- `src/shared/tokenStorage/index.ts`：預設策略與 `get/setXxxTokenStrategy` 出入口
