# 前端部署指南（Vercel）

1. Vercel -> Add New -> Project，從 GitHub 選擇前端專案儲存庫。
2. 專案根目錄為本 repo 根目錄（原 Grafana-Test-data-ver2）。
3. 在 Settings -> Environment Variables 設定環境變數：
   - `VITE_API_BASE_URL`（必填）：Zeabur 後端網址，例如 `https://xxx.zeabur.app`
   - 其餘變數依 `.env.example` 設定。
4. 正式環境分支設為 `main`。

完成設定後重新部署，並以正式網址驗證登入與受保護 API 流程。
